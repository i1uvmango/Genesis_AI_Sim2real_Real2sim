# Occluded Road Recovery Pipeline

> 차에 가려 한 번도 안 보인 도로 칸을 **가려진 방식에 따라 3갈래**로 나눠 채운다 — 다른 시점 → 주변 복사 → prior 합성 순

## 차량이 가린 도로 정보 Prior로 채우기

### 전체 흐름

```
① 도로 칸 분류 (관측 횟수, 마스크 모양)
   ├─ 잘 보임 ──────────────▶ 학습한 색 그대로
   ├─ 차 1대에 도로 가려짐 ───────▶ ② 다른 시점에서 찾기 → 없으면 ③ 주변으로 채우기
   └─ 차 여러대에 도로 가려짐 ────▶ ④ 차로 배치 prior + 우리 아스팔트로 합성
                    ↓
⑤ 학습에 반영 (안 보인 칸은 색 고정) → ⑥ 평가 (합성 칸 비율 따로 보고)
```

---

## 도로 칸 분류

| 분류 | 판정 기준 | 근거 데이터 | 처리 |
|---|---|---|---|
| Observed | 지면 2회 이상 관측 | 관측 횟수 | 학습한 색 그대로 |
| single vehicle occlusion | 차 한 대(약 5 × 2 m), 주변은 보임 | 덩어리 크기, SegFormer 차량 덩어리 수 | - |
| Multi vehicle occlusion | 같은 차로를 따라 **10 m 이상** 이어져 안 보임 | 위와 같음 | ④ |

**구멍의 크기와 모양이 처리 방법을 정함**

* single vehicle occlusion → 주변 정보로 충분
* 긴 구멍 → 주변에도 정보가 없어 외부 prior 필요

### 2. single vehicle occlusion - 다른 시점 영상으로 채우기

| 항목 | 현재 | 변경 |
|---|---|---|
| 시간 범위 | 8초 블록 + 앞뒤 1초 | **60초 전체** |
| 카메라 | — | 그 지점을 본 모든 프레임 × 4방향 |
| 프레임 | — | **15 fps** — 차가 조금씩 움직인 순간을 잡음 |

**실제 관측을 늘리는 방법이라 가장 먼저 시도함**

* 후방 카메라 → 차가 지나간 **뒤** 그 자리 도로를 봄
* 찾은 사진 조각은 관측 개수만큼 학습에 들어감 — 별도 처리 없이 지금 학습에 그대로 반영

### 4. Multi-vehicle occlusion : Prior 와 합성

### 4-1. 도로 Prior (모양)

| 순위 | 출처 | 얻는 것 | 쓰는 방법 |
|---|---|---|---|
| 1 | 국토부 **정밀도로지도** (우리 구간이 있으면) | 차선 위치, 실선·점선, 노면 표시 | 그대로 사용 |
| 2 | **OSM** | 차로 수, 일방통행 | 정밀도로지도가 없을 때 차로 수만 |
| 보조 | 네이버 거리뷰 (보기만) | 차로 수, 차선 종류, 화살표·횡단보도 위치 | 사람이 보고 숫자로 기록. 사진은 저장하지 않음 |
| 보조 | 우리 영상의 보이는 구간 | 점선 길이·간격(주기, 위치), 차선 폭 | 보이는 차선 검출 → 주기 맞춤 → 가려진 구간으로 이어 그림 |

**지도는 차로 "배치"만, 실제 치수는 우리 영상에서 가져옴**

### 4-2. 색과 질감

| 대상 | 방법 |
|---|---|
| 아스팔트 | 같은 블록에서 실제로 보인 우리 도로(자차 차로 등)를 표본으로 이어 붙여 합성 |
| 차선 | 4-1 배치대로 흰색·노란색 선, 화살표를 그려 넣음 |
| 테헤란로 구간 | KAIST urban30 에서 그 차로가 보이면 **실제 사진 우선** — 촬영 시기는 다르지만 실제 관측 |
| 표시 | 합성한 칸에는 `prior 기반` 표시를 남김 |

## ⑤ 학습에 반영

| 방법 | 내용 | 목적 |
|---|---|---|
| 안 보인 칸 색 고정 | 관측 0회 Gaussian 은 학습 중 색 고정 | 마스크 가장자리에서 새는 차 색이 원색 점을 만드는 것 방지 |
| 약한 prior | 합성 색 쪽으로 약하게 당기는 손실 | 관측이 조금이라도 있으면 관측이 이김 |
| 최종 덮어쓰기 | 학습 후 관측 0회 칸만 합성 텍스처로 교체 → 텍스처로 구움 | 합성은 마지막에만 개입 |

**합성 색이 실제 관측을 이기지 않도록 3단계로 막음**
