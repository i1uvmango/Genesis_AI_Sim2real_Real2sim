홈

WMTS API 레퍼런스

이전화면
소개
  • WMTS(Web Map Tile Service)를 통해 고품질의 배경지도를 제공합니다.
  • 인증된 키를 사용하여 요청 URL을 서버에 전송하면 WMTS 서비스를 활용하실 수 있습니다.
WMTS GetTile 요청URL
https://api.vworld.kr/req/wmts/1.0.0/{key}/{layer}/{tileMatrix}/{tileRow}/{tileCol}.{tileType}
  • 예) https://api.vworld.kr/req/wmts/1.0.0/{key}/Base/11/793/1746.png
WMTS GetTile 요청URL(해외위성영상)
https://api.vworld.kr/req/wmts/1.0.0/{key}/Satellite/themes/{category}/{year}/{city}/{tileMatrix}/{tileRow}/{tileCol}.{tileType}
  • 예) https://api.vworld.kr/req/wmts/1.0.0/{key}/Satellite/themes/cities/2025/Oslo/11/1086/596.png
WMTS GetCapabilities 요청URL
  • https://api.vworld.kr/req/wmts/1.0.0/{key}/WMTSCapabilities.xml
