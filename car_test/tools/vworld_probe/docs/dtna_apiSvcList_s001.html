전체메뉴

로그인 후 디지털트윈국토의 모든 서비스를 이용해 보세요.

로그인 회원가입

  • 관심메뉴 설정

    : 클릭 시 관심메뉴로 등록되어 마이포털에서 바로가기를 제공합니다. 지도메뉴의 관심설정은 지도 전체메뉴에서 설정해 주세요.

  • 회원전용 메뉴

    : 자물쇠 표시가 있는 메뉴(하위 메뉴 포함)는 로그인 후 이용가능합니다.
홈

  • 국가중점데이터API 레퍼런스

    유형REST 저작자표시저작자표시-동일조건 심의유형관리자 출처표시출처표시-상업적,비상업적 이용가능-변형 등 2차적 저작물 작성 가능
    이전화면

서비스 제공방식

  • WMS(Web Map Service) 서비스는 지리 데이터에서 생성된 맵 이미지(png, jpg, gif)를 활용할 수 있도록 합니다.
  • WFS(Web Feature Service) 서비스는 (벡터 도형 및 속성을 지닌) 지리 피처 데이터를 활용할 수 있도록 합니다.
  • 속성속성 서비스는 XML, JSON 데이터를 활용할 수 있도록 합니다.
