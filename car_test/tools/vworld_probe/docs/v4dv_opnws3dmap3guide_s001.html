웹지엘 3D지도 API 3.0

버전 2.0 이전화면
  • 레퍼런스
  • 코드샘플
소개
  • WebGL 기반으로 개발되었으며, javaScript로 제공됩니다.
  • 웹지엘 3D지도 API 3.0은 웹지엘 3D지도 API 2.0의 기능을 유지하면서 사용자 친화적 설계로 사용성을 향상시켰습니다.
  • GIS 표준을 준수하여 다른 API 사용자의 진입 장벽을 최소화하였습니다.
  • API를 사용하려면 브이월드 회원가입 후 '마이포털'에서 인증키를 받아야 합니다.
  • 사용자는 Cesium의 일부 기능을 활용할 수 있으나, 모든 기능을 지원하지 않습니다.

기능은 향후 변경 및 개선될 수 있으며, 추가 지원 내용은 추후 업데이트 예정입니다.(자세히보기)

3D지도 초기옵션 설정 및 호출방법
버전 2.0
  • vw.Map 클래스 생성
  • vw.MapOptions 클래스를 이용해서 지도를 생성
									//예시
									var mapOptions = new vw.MapOptions(vw.BasemapType.GRAPHIC, "",
									    vw.DensityType.BASIC,
									    vw.DensityType.BASIC,
									    false,
									    new vw.CameraPosition(
									        new vw.CoordZ(126.96205520098383, 37.49901882622055, 2400),
									        new vw.Direction(0, -90, 0)
									    ),
									    new vw.CameraPosition(
									        new vw.CoordZ(126.96205520098383, 37.49901882622055, 2400),  
									        new vw.Direction(0, -90, 0)
									    )
									);
									
									var map = new vw.Map("vmap", mapOptions);
버전 3.0
  • vw.Map 클래스 생성
  • start()를 활용하여 지도 생성
									//예시
							        var options = {
							            mapId: "vmap", // 지도맵 컨테이너 아이디
							            initPosition: new vw.CameraPosition( // 초기 위치
							                new vw.CoordZ(126.921883, 37.524370, 2400),
							                new vw.Direction(0, -90, 0)
							            ),
							            logo: true, // 하단 로고 설정. true : 표출, false : 미표출
							            navigation: true // 오른쪽 상단 네비게이션 설정. true : 표출, false : 미표출
							        };
							
							        var map = new vw.Map();
							        map.setOption(options); //3D지도 초기 옵션 설정
							        map.setMapId("vmap"); //지도가 탑재될 컨테이너 설정 가능
							        map.setInitPosition(new vw.CameraPosition( //초기 위치설정 가능
							            new vw.CoordZ(126.921883, 37.524370, 24000),
							            new vw.Direction(0, -90, 0)
							        ));
							
							        // 로고 및 네비 설정.
							        map.setLogoVisible(true);
							        map.setNavigationZoomVisible(true);
							        map.start(); // 설정 항목을 가지고 최종지도생성
세슘기능 확장
버전 2.0
  • 별도 Cesium JS 파일 선언 후 Cesium 기능 활용 가능
  • Cesium 공식 문법이 아닌 WebGL 엔진 문법을 활용하여 기능 수행
										
										
										//예시
										ws3d.common.Cartesian3.fromDegrees(-117.16, 32.71, 15000.0)	//WebGL 엔진문법
버전 3.0
  • 별도 Cesium JS 파일 선언 필요없이도 Cesium 기능 활용 가능
  • Cesium 공식 문법을 통하여 Cesium 기능 수행 가능
									// 예시								
									ws3d.common.Cartesian3.fromDegrees(-117.16, 32.71, 15000.0) //WebGL 엔진문법
									=
									Cesium.Cartesian3.fromDegrees(-117.16, 32.71, 15000.0) //Cesium 공식문법

세슘기능 확장

웹지엘 3D지도 API 3.0은 별도의 Cesium JS 파일 선언 필요 없이도 Cesium 기능 활용이 가능합니다.

활용예시

Cesium scene 객체 = ws3d.viewer.scene;
Cesium camera 객체 = ws3d.viewer.camera;

Cesium 기능 응용
ws3d.viewer.camera.flyTo({ //setView
             destination: Cesium.Cartesian3.fromDegrees(경도,위도,높이),
                orientation: {
                heading: Cesium.Math.toRadians(heading수치),
                  pitch: Cesium.Math.toRadians(pitch수치)
                roll: 0.0,
                },
});

Cesium 문법 활용
- Cesium.Cartesian3.fromDegrees(-117.16, 32.71, 15000.0)
