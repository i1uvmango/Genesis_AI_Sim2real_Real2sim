# V-World probe findings (2026-11-06)

키는 같은 폴더의 .env 에 둠 (genesis-doc/.gitignore 의 *.env 로 제외). 1·2·4는 공식 문서와 카탈로그 API로, 3과 건물 외곽선은 키로 실제 호출해 확인함.

| 질문 | 판정 | 확인한 근거 (docs/, raw/) |
|---|---|---|
| 1. 3D 건물 받기 | 공개 API·다운로드로는 불가, 기관 요청으로만 가능 | 다운로드 상세 detail_125/203/204: LoD4·LoD3·LoD1 모두 "데이터 확보방식: 구축 기관에 문의", 유형 "지도조회". 카탈로그 API 658개 데이터셋에 3D 건물 없음 |
| 2. 텍스처 | LoD4·LoD3은 있음, LoD1은 없음 | LoD4 원본 3ds + jpg, 서비스 xdo + jpg, 항공 경사촬영 5방향. LoD3 원본 3ds + jpg, 서비스 지역은 대구. LoD1 원본 shp, 층수 × 3 m 박스. 해상도 표기 없음 |
| 3. 정사영상 타일 | **가능 (실측)** | Satellite z19 타일 256×256 jpeg 수신, z20은 예외 응답 → 최대 z19, 0.237 m/px. samples/z19_mosaic_3x3.jpg. 차선·횡단보도는 보이나 차량이 찍혀 있고, 건물이 기울어 보여 도로를 가리며(정사 보정만 된 항공사진), 일부 구역은 보안 처리로 뭉개짐 |
| 4. 차선 정보 | V-World API로는 불가, 국토지리정보원 다운로드로 가능 | 2D 데이터 API 158종에 정밀도로지도 레이어 없음. 다운로드 상세 detail_214: shp, 국토지리정보원 링크 |

추가 실측: WFS lt_c_spbd (도로명주소 건물) 200 m 상자에서 21개 건물 MultiPolygon + 지상·지하 층수 수신 (raw/wfs_lt_c_spbd.json.txt). 예: 강남파이낸스센터 지상 45층, GS타워 38층. 높이(m)는 없어 층수로 추정해야 함.
실행: `python -I probe.py` (키는 .env 에서 읽음, 저장 파일에는 <KEY> 로 가림).

추가 (2026-11-06): 3단계 개편의 glb·gltf·collada·obj·dae·3ds 지원은 **사용자 3D 모델을 지도에 올리는 기능**임. 지도 페이지(docs/dtkmap.html)의 해당 창은 파일 업로드 입력(`accept=".glb,.gltf"`, "로컬 좌표계 값은 (0, 0, 0)")이고, 국가 3D 건물을 내려받는 기능이 아님. 같은 페이지의 다운로드는 "샘플모델 다운로드"뿐임.
