STORM의 답

Transformer가 사진에서 3D Gaussian + 속도를 한 번에 냄 → ①

움직임은 라벨 없이 재구성 손실만으로 배움 (self-supervised scene flow) → ③

STORM 신경망 학습 : 입력에 없던 시각으로 채점해야 거리와 움직임을 배움

입력 : 2초 구간의 시각 t, t+0.5, t+1.0, t+1.5 (카메라 3대)

채점 : 같은 구간에서 무작위 시각 4개, 같은 카메라 3대

Gaussian을 속도로 채점 시각에 옮겨 모음(amodal) → 렌더 → 실제 사진과 비교
